# 测试指南

## 回归与构建

在项目根目录运行：

```bash
npm test
npm run build
```

`npm test` 依次运行 `tests/server/` 的 Node 测试与 `renderer/` 的 React 测试，也可以分别使用 `npm run test:desktop` 和 `npm run test:renderer`。服务测试使用临时数据库与模拟服务；React 测试使用 jsdom。

账号组件测试覆盖保存成功但列表刷新失败时保留已确认数据、保存失败保留输入并允许重试、列表错误不冒充空列表，以及打开公众号时保留现有平台页面。保存状态不作为登录有效性的证据。

## Electron 流程

先构建，再运行：

```bash
npm run test:smoke
npm run test:workflow
npm run test:layout
npm run test:visual
npm run test:review
npm run test:research
npm run test:wechat
```

这些测试均启动真实 Electron 窗口并使用独立临时数据目录，不读取日常业务数据。

| 测试 | 覆盖 |
| --- | --- |
| `test:smoke` | 进程隔离、访问控制、独立平台窗口、新建、编辑、保存、图片插入、SKILL.md 预览确认安装及重启保留；禁用后台任务 |
| `test:workflow` | 文章接入、标题随版本更新、Agent 候选稿审批、失败保护、Skill 文件夹安装与可见调用、图片提示词审批、参考图预览、结果选择、上传、文生图、图生图、兼容 Webhook 发布、公众号锁定版本与执行步骤、重启恢复 |
| `test:layout` | 工作区 1440/1200/800/390/320px 布局及四个主页面 390/320px 布局、导航收展、弹层焦点恢复、正文滚动与输入保留、待确认入口、深色模式、关键文字与占位文字 4.5:1 对比度、44px 触控目标、200% 实际缩放；禁用后台任务，不发布 |
| `test:visual` | 文章列表、工作区、Skills、发布与设置的双主题截图及 1440/1200/800/390/320px 布局；摘要行数、真实筛选与来源搜索、44px 按钮、品牌导航关闭抽屉，以及短窗口审批与展开帮助时的输入保留；使用临时测试文章，不调用模型或发布 |
| `test:review` | 未保存正文参与改稿、生成期间继续编辑、增删对比、拒绝与接受、刷新恢复基准、服务端版本冲突、保存期间编辑保护、应用内导航保留、取消关闭后保存 |
| `test:research` | 逐条查询、四类结论、证据摘录、候选稿不覆盖正文、报告刷新恢复、窄屏抽屉与键盘、失败不残留旧结论、重新核查和接受 |
| `test:wechat` | 在本地模拟公众号编辑页验证官方域名保护、登录接管、语义定位填写、本机图片原生粘贴、剪贴板恢复、填写后单独确认、点击前标题/正文/图片复核、平台确认弹层与明确成功证据；不登录或发布到真实公众号 |

`test:visual` 还会用 14 篇临时文章检查 1474×1048px 窗口下的内容起点、列表顶部、行高与首屏完整行数。可通过 `AI_MEDIA_VISUAL_OUTPUT` 指定本轮截图和报告目录，以保留前后对照。

完整流程启用后台 worker，文本和图片响应来自本机 HTTP 模拟服务，不产生模型费用。报告与截图写入 `artifacts/desktop-workflow.*`，基础检查截图为 `artifacts/desktop-smoke.png`。

对话分流的服务与组件测试覆盖改稿、配图、发布预览、澄清和非法模型输出；识别阶段不得创建候选稿、图片或发布任务。完整流程还通过自然语言进入配图审批和发布预览，并检查配图使用未保存正文。这里固定了模型的分类响应，只验证接线与审批安全，不代表真实模型已通过否定语义、混合要求或识别准确性验收。

连续对话测试覆盖同篇文章隔离、近期条数和字符上限、候选稿接受/拒绝状态、旧正文和工具权限不进入历史上下文、对话写入失败回滚、配图失败后重试及不继承审批。桌面流程验证模型收到上一轮澄清记录，配图与澄清对话在刷新和重启后仍可查看，但不会恢复生图确认；组件测试验证旧候选稿不重新待审批，最新请求为配图时不误显示上轮 Skill。

候选稿迭代测试覆盖原始对比基准不变、候选稿作为下一轮输入、事实核查输入标识、处理中禁止接受/拒绝、失败恢复上一版、成功后原候选稿失效、只有最终候选稿创建一个版本，以及候选稿替代与审计记录的事务回滚。前端同时验证待确认时可继续输入、配图按钮仍禁用、失败后上一版可继续处理。

配图 Skill 测试覆盖图片能力自动匹配、选择器明确指定、未命中时不静默套用写作 Skill、说明和参考资料进入提示词、执行记录即时展示与刷新恢复，以及模型请求期间停用或撤回权限后作废结果。测试同时确认：准备提示词不会创建生图审批、媒体资源或调用图片模型。

Skill 服务与组件测试额外覆盖：取消预览不写入、非法 YAML/版本/权限、目录和引用边界、过期或篡改的确认、并发更新冲突、自动/明确调用、权限撤回、失败后重新预览，以及保留已有停用状态。安装预览截图为 `artifacts/skill-install-approval.png`。

布局报告与截图为 `artifacts/workspace-layout.json` 和 `artifacts/workspace-*.png`。商业视觉检查输出到 `artifacts/studio-redesign-2026-09-10/`，包括双主题与窄屏截图、成功空状态及 `verification.json`；其中的测试文章不会写入日常数据库。组件测试补充标签键盘操作、抽屉切换时不重复渲染资料、待审批时保留下一轮输入。布局验证不等于全站可访问性合规；模拟公众号测试也不能替代真实登录账号和当前线上页面验收。

改稿报告为 `artifacts/article-review.json`，截图为 `artifacts/article-review-*.png`，使用本地模拟模型。服务测试另外覆盖重复接受不新增版本、旧保存和恢复请求被拒绝、审计写入失败整次回滚、缺少基准的旧候选稿不能接受；前端覆盖 HTML 惰性展示、长文降级、数据刷新不覆盖编辑。关闭确认只在隔离测试应用中模拟用户选择。

核查测试复用生产 API、页面与 preload，在独立 Electron 测试入口注入检索和模型响应；不连接付费服务，也不验证生产 worker 的进程隔离（由 smoke/review 另验）。报告为 `artifacts/fact-check.json`，截图为 `artifacts/fact-check-*.png`。服务测试覆盖原句不匹配、伪造来源或引文、跨说法引用、只有摘要、检索/模型失败、未授权搜索、取消、长文范围和数据库重启恢复。模拟结论不能替代真实服务的核查质量验收。

可通过 `AI_MEDIA_EXECUTABLE` 指向打包后的可执行文件，运行相同的流程。例如 Apple Silicon 构建：

```bash
AI_MEDIA_EXECUTABLE="$PWD/release/mac-arm64/AI Media.app/Contents/MacOS/AI Media" npm run test:workflow
```

## 真实服务验收

`npm run test:live` 只在显式指定 `AI_MEDIA_ACCEPTANCE_SOURCE` 后执行，会调用付费文本、检索和图片服务。数据目录需要包含已配置服务的 `ai_media.db` 及关联媒体：

```bash
AI_MEDIA_ACCEPTANCE_SOURCE="/absolute/path/to/storage" npm run test:live
```

请关闭使用该数据目录的应用后执行，确保原文件校验不受并发写入影响。测试只读源库，在临时目录验证导入、真实改写与检索、Agent 逐条事实核查与拒绝候选稿、生图、图片编辑、上传与版本及重启恢复。发布目的地是本机测试 Webhook，不向外部平台公开发文。

公众号模拟测试额外覆盖外部图片直链接管、图片上传失败和用户并发复制内容的保留。完整桌面流程覆盖结果不明时拒绝直接重填、人工核对未发布后恢复填写；界面和服务测试覆盖人工确认已发布、重复核对被拒绝及不能通过取消绕过核对。核对弹窗有 320/390px 布局检查，截图为 `artifacts/wechat-outcome-review*.png`。

文本与搜索配置优先取自根 `.env`，其余取自源库。可按需设置：

| 变量 | 说明 |
| --- | --- |
| `AI_MEDIA_ACCEPTANCE_SCOPE` | `text` 验收检索与改稿；`conversation` 验收对话分类；`image` 仅在确认提示词后验收一次文生图和一次图生图。默认 `full` 验收全部服务，同样需要确认图片提示词 |
| `AI_MEDIA_ACCEPTANCE_IMAGE_BASE_URL` | 本次测试使用的图片 API 地址 |
| `AI_MEDIA_ACCEPTANCE_IMAGE_CUSTOM_SIZE_QUALITY` | `0` 不发送尺寸和质量参数，`1` 发送；未设置时沿用源配置 |

报告写入 `artifacts/live-acceptance.json`，测试结束删除临时数据。真实服务结果与模拟测试结果分别记录，不用一类结果替代另一类验收。

对话专项报告单独写入 `artifacts/live-conversation.json`，不覆盖真实求实报告。覆盖否定要求、只准备配图、要求跳过确认的发布指令、文章中提及图片/发布但只要求改字、混合动作澄清及后续选择；检查识别没有创建改稿运行、图片、审批或发布任务。这些固定样例不能代表所有表达方式均正确。

图片专项报告写入 `artifacts/live-image.json`，生成和编辑结果以独立文件名保存在 `artifacts/live-image-*`，不覆盖旧图片；同时验证生成图片不会自动修改正文或发文。图片内容仍须人工查看，接口通过不代表画面质量合格。

## 当前真实公众号验收阻碍（2026-09-04）

遗留隔离测试进程已停止，日常 AI Media 窗口可以连接；但进入公众号页面后，电脑操作工具明确拒绝访问该 URL 并终止会话。这不是仍在等待的请求，禁止通过重试或其他工具绕过限制。本次没有填写或发布。

这一限制不改变产品自动发布目标。应用已实现有界语义导航，本地模拟测试覆盖首页创作入口到编辑器、重复入口停止、不安全链接、验证码停止、超时后重试、导航不发布及已有平台草稿保护；测试禁止外网请求，使用独立账号数据目录，不访问真实公众号。真实入口兼容性和发布验收仍需在允许的环境中验证，并逐次确认账号和最终文章；当前不能标记为完整验收通过。
