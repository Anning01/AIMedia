# 万稿汇产品资料

## 产品名称

万稿汇（WanGaoHui Studio）

## 官网链接

## 产品定位

面向个人创作者、内容运营者和代运营团队的桌面端 AI 内容生产与发布工具，帮助用户完成“选题/素材整理 → AI 生成 → 内容排版 → 配图 → 草稿保存或发布 → 定时托管”的内容工作流。

万稿汇运行在用户电脑上，创作数据和平台账号信息主要保存在本机，适合需要批量生产和管理公众号、小红书及其他内容平台内容的用户。

## 产品简介

万稿汇是一款基于 Electron 的 Windows 桌面应用，提供资源管理、公众号文章创作、贴图制作、小红书笔记复刻、账号管理、内容发布和任务托管等能力。

用户可以输入文章主题、关键词或已有素材，先生成文章大纲，再生成完整正文，并将内容转换为标题、正文、小标题、引用、卡片、列表、提示和 CTA 等结构化模块。生成结果可以在编辑器中继续修改，套用排版模板，自动或手动添加图片，并保存为草稿或发送到已授权的平台账号。

## 核心功能

### 1. 资源与素材管理

- 管理热点、微信爆文和图片素材等内容资源。
- 导入 TXT、Markdown 等本地文字素材。
- 创建和编辑素材组，支持为素材配置平台、内容类型和账号备注。
- 对图片素材进行标签管理和搜索。
- 保存文章历史、贴图历史、产品资料和个人图片素材。

### 2. 公众号文章生成

- 输入文章主题、关键词或已有文章素材。
- 先生成文章大纲，再生成完整文章正文。
- 支持标题、正文、小标题、引用、卡片、列表、提示、分割线、CTA 等内容模块。
- 支持已有素材重写，尽量保留原始事实、核心观点和限制条件。
- 支持通过 AI 生成内容策略、文章结构和传播角度。
- 支持中文内容与日文中间稿之间的生成、翻译和校验流程。
- AI 返回结构化内容时直接转换为编辑器模块；结构化结果失败时提供文本解析兜底。

### 3. 文章排版与编辑

- 内置多种公众号文章排版模板。
- 支持调整配色、字体、字号、标题、小标题、引用、列表、卡片和 CTA 样式。
- 支持文章模块增加、删除、编辑和排序。
- 支持手机效果预览。
- 支持将排版后的 HTML 复制到公众号后台。
- 支持保存为草稿、加入待发布队列和保存生成历史。

### 4. 文章配图

- 支持上传本地图片或从图片库选择图片。
- 支持根据文章标题、小标题和正文内容自动匹配图片素材。
- 自动配图支持 AI 标签匹配，AI 选择失败时使用关键词匹配作为兜底。
- 支持对图片进行本地保存、读取和统一管理。
- 支持控制自动配图数量。

### 5. 贴图制作

- 支持公众号封面、正文卡片、小红书 3:4 图片和长图等画布尺寸。
- 支持首图模板和内容卡模板。
- 支持编辑图片中的标题、正文、颜色、字体、位置和对齐方式。
- 支持将文章或贴图文字渲染为图片。
- 支持上传图片、使用图片库素材和保存个人模板。

### 6. 小红书笔记复刻

- 支持输入小红书笔记链接或粘贴笔记正文。
- 对笔记进行标题、正文结构、标签、情绪词和图片特征分析。
- 根据原笔记的结构和风格，结合用户自己的产品信息生成新的笔记内容。
- 支持为笔记上传、选择或生成配图。
- 支持将笔记内容和图片复制或发布到小红书创作流程。
- 该能力属于平台自动化场景，存在登录态、反爬和账号风控风险。

### 7. 多平台账号与发布

- 支持公众号、头条号、百家号和小红书账号管理。
- 支持扫码或网页登录获取平台登录状态。
- 公众号支持同步名下多个账号。
- 支持配置账号备注、内容声明、原创/首发等发布参数。
- 支持公众号草稿保存和发布。
- 支持头条号、百家号等平台的内容发布流程。
- 支持发布历史、待发布队列和失败状态记录。

### 8. 自动任务托管

- 支持创建一次性或每日任务。
- 支持配置内容来源、处理类型、配图方式、生成数量、开始时间和发布目标。
- 支持从素材、热点或微信爆文中生成文章或贴图。
- 支持任务暂停、执行、日志查看和失败重试。
- 支持将生成内容保存为草稿或尝试自动发布。

### 9. AI 配置与更新

- 启动无需器灵激活或授权码。
- 支持自定义 OpenAI 兼容服务、模型和 API Key，密钥加密保存在本机。
- 只提供文本接口配置与连接测试，生成和回译统一使用保存的文本模型。
- 器灵支持可选的一键授权、手动 Key 和实时文本模型选择；去 AI 由用户主动触发并按器灵接口规则结算。
- 支持客户端检查更新、下载更新和安装更新。

## 使用场景

- 个人公众号作者：输入一个主题，生成文章大纲、正文、排版和配图，保存到公众号草稿箱。
- 小红书运营者：分析一篇参考笔记的结构，结合自己的产品信息生成新的笔记和配图。
- 内容代运营团队：统一管理多个平台账号，批量生产不同账号的内容并记录发布状态。
- 电商或品牌团队：维护产品资料和素材库，持续生成公众号文章、种草笔记和宣传贴图。
- 日常内容排期：创建定时任务，按天从素材库生成内容并保存草稿或执行发布。

## 产品原始资料

### AI 写作必须遵守的真实资料

- 产品名称为“万稿汇”，英文名为“WanGaoHui Studio”。
- 产品是桌面端应用，技术实现采用 Electron、Vite、React 和 TypeScript。
- 产品主要服务于内容创作和内容发布，不是内容平台本身。
- 用户输入可以是主题、关键词、已有文章、TXT/Markdown 素材或小红书笔记内容。
- 文章生成流程包含：输入检查、大纲生成、内容生成、中文翻译/回译、文本清理、校验、结构化排版和编辑器展示。
- 文章生成结果可能受到模型、网络、翻译服务、服务商额度和素材质量影响，不能承诺每次生成结果完全正确。
- 产品可以降低模板化表达，但不能宣称“100% 通过 AI 检测”、保证爆款或保证发布后获得流量。
- AI 生成内容必须以用户提供的真实素材和事实为基础，不得凭空编造人物、经历、数据、机构、采访、研究或案例。
- 重写已有文章时，应复用事实和核心观点，不能直接复制原文，也不能把参考文章的具体内容冒充为用户原创。
- 公众号、头条号、百家号和小红书的登录、发布接口及页面规则可能变化，发布成功率取决于平台状态、账号权限和登录状态。
- 小红书没有稳定的通用官方发布接口，相关自动化能力存在平台规则、反爬和账号风控风险，应优先提示用户采用人工确认或半自动流程。
- 用户需要对最终发布内容的真实性、版权、广告合规、平台规则和账号安全负责。
- 用户的账号登录态、Cookie、Token、文章记录和素材数据主要保存在本机；AI 调用和平台发布仍需要网络连接。
- 官网链接、客服电话、客服微信未在项目资料中明确，不得自行补充或猜测；应用内无套餐购买或积分计费。

### 当前产品边界

- 当前重点是内容生产、编辑、排版、素材管理和发布辅助。
- 不应将产品描述为保证文章质量、保证流量、保证平台审核通过或保证账号不被限制的工具。
- 生成文章后仍建议由用户进行事实核查、版权检查和发布前审核。
