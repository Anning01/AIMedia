# 万稿汇 · 贴图功能接入说明

> 面向其他应用的贴图功能说明：从模板、生成、渲染到发布的全流程，含数据结构与接入建议。

## 1. 整体流程

```text
用户输入主题/素材
    │
    ▼
AI 生成贴图内容（标题 + 分段正文 + 话题）
    │
    ▼
模板渲染（首图 + 内容卡，HTML/CSS → PNG）
    │
    ▼
预览 / 编辑（可换模板、重新渲染、手动调整）
    │
    ▼
发布（公众号/小红书：正文 = 标题 + 话题）
```

核心原则：**文字渲染进图片，发布只带标题和话题**。

## 2. AI 生成

### 2.1 提示词

默认系统提示词：

```text
你是资深公众号贴图内容策划。根据输入的内容，提取关键信息，去掉无用广告和清洗不干净的遗留信息，
生成一条公众号贴图内容：
第一行是贴图标题（一句有吸引力的短句，不超过 25 个字）；
接着是正文描述（口语化、有画面感，按段落输出，每段 60~100 字左右，
段落之间用空行分隔，每段适合单独做成一张卡片）；
不要任何 Markdown 标记、列表符号或格式符号；
最后另起一行生成 3 到 5 个合适的话题，每个话题以 # 开头、用空格分隔。
只输出标题、正文和话题，不要任何额外说明。
```

用户提示词模板：

```text
贴图主题：{topic}
字数：{words}（默认 400 字以内，可选 300/200）
```

### 2.2 输出格式

```text
十二星座里，真正把孝顺刻进骨子里的，是这三个
前几天在家庭群里看到一条消息……

巨蟹座：孝顺是接起电话的那一刻
……

#星座孝顺 #巨蟹座 #金牛座 #处女座 #十二星座
```

解析规则：

| 位置 | 内容 |
| --- | --- |
| 第 1 行 | 贴图标题（≤25 字） |
| 中间段落（空行分隔） | 正文，每段一张内容卡 |
| 以 # 开头的行 | 话题，发布时拼在正文末尾 |

### 2.3 说明

- 贴图内容直接由 AI 生成，不经过文章的去 AI 核心流程
- 生成成功后按 `贴图 10 积分/条` 扣费（接入主站 AI 网关）

## 3. 模板体系

### 3.1 模板分类

- **首图模板**：渲染贴图标题，输出第一张主图
- **内容卡模板**：渲染正文段落，每段一张卡片

内置模板为参数化模板，核心字段：

```json
{
  "id": "f01",
  "name": "经典黄框",
  "cat": "边框语录",
  "variant": "border",
  "bg": "#FFD60A",
  "frame": "#FFFDF5",
  "titleColor": "#1A1A1A",
  "textColor": "#4a4a4a",
  "accent": "#FFD60A",
  "titleSize": 9.5,
  "textSize": 3.8,
  "layout": "center",
  "highlight": "circleUnderline",
  "badge": "语录",
  "titleFont": "smiley",
  "showPage": true,
  "showArrow": true
}
```

### 3.2 自定义模板（高级能力）

自定义模板在参数化模板基础上扩展：

```json
{
  "source": "custom",
  "bgImage": "data:image/png;base64,...",
  "cardBgImage": "data:image/png;base64,...",
  "customCSS": ".sticker-cover-zone { ... }",
  "coverZones": [
    {
      "x": 12, "y": 36, "w": 76, "h": 24,
      "size": 58, "color": "#1A1A1A",
      "align": "center", "bold": true, "maxLines": 2
    }
  ],
  "cardZones": {
    "heading": { "x": 10, "y": 10, "w": 80, "h": 18, "size": 30, "color": "#1A1A1A", "align": "center", "bold": true, "maxLines": 2 },
    "text": { "x": 10, "y": 32, "w": 80, "h": 55, "size": 24, "color": "#333333", "align": "left", "bold": false, "maxLines": 10 }
  }
}
```

文字区域字段（百分比定位）：

| 字段 | 说明 |
| --- | --- |
| x / y | 区域左上角（画布百分比） |
| w / h | 区域宽高（画布百分比） |
| size | 字号（900px 设计稿基准） |
| color | 文字颜色 |
| align | left / center / right |
| bold | 是否加粗 |
| maxLines | 最大行数，超出隐藏 |

自定义模板与内置模板使用同一套渲染与发布链路，接入方只需按同构数据结构实现。

## 4. 渲染（独立实现规格）

> 接入方完全独立实现渲染，本部分为不依赖万稿汇代码的完整规格。

### 4.1 输出规格

| 类型 | 输出尺寸 | 比例 | 内容 |
| --- | --- | --- | --- |
| 首图（封面） | 900 × 1200 | 3:4 | 贴图标题 |
| 内容卡 | 900 × 1200 | 3:4 | 正文段落（每段一张），话题放最后一张 |

所有模板统一按 900 × 1200 设计稿规格，文字区域坐标、字号都以这个画布为基准。

### 4.2 渲染单位

每次渲染只有两种单位：

1. **Cover（首图）**：输入 = 模板 + 标题文本
2. **Card（内容卡）**：输入 = 模板 + 小标题（可选）+ 正文段落

话题不单独渲染成文字卡：话题拼到正文最后一段之后，作为最后一张内容卡的文字内容。

### 4.3 渲染原理

推荐方案：**用 HTML + 内联样式构建 DOM，再用 html-to-image（或等价 canvas 截图库）输出 PNG**。

为什么用 DOM 而不是 canvas 手绘：

- 模板样式（渐变、边框、圆角、阴影、换行、中文字体）全部由 CSS 表达，成本低
- 自定义背景图、文字区域、customCSS 天然支持
- 预览和导出共用同一套 DOM，所见即所得

像素比计算（预览节点较小，导出要高清）：

```text
预览节点：168 × 224（3:4）
目标输出：900 × 1200
pixelRatio = max(900 / 168, 1200 / 224) ≈ 5.36
toPng(node, { pixelRatio: 5.36, backgroundColor: 'transparent' })
```

任何渲染库只要支持 `pixelRatio`（如 html-to-image、html2canvas、Puppeteer 截图）都可以。

### 4.4 首图 DOM 结构

根节点约定（自定义模板）：

```html
<div class="sticker-cover" style="position:relative;width:900px;height:1200px;overflow:hidden;background:#FFD60A;border-radius:12px;box-sizing:border-box;">
  <!-- 背景图（可选）：铺满 -->
  <div style="position:absolute;inset:0;background-image:url(data:image/png;base64,...);background-size:cover;background-position:center;"></div>

  <!-- 文字区域：绝对定位，百分比坐标 -->
  <div class="sticker-cover-zone"
       style="position:absolute;left:12%;top:36%;width:76%;height:24%;
              font-size:58px;color:#1A1A1A;font-weight:800;text-align:center;
              font-family:'Smiley Sans','Microsoft YaHei',sans-serif;line-height:1.35;
              display:-webkit-box;-webkit-line-clamp:2;-webkit-box-orient:vertical;
              overflow:hidden;overflow-wrap:anywhere;white-space:pre-wrap;">
    十二星座里，真正把孝顺刻进骨子里的，是这三个
  </div>

  <!-- 自定义 CSS（可选） -->
  <style>.sticker-cover-zone { letter-spacing: 0.02em; }</style>
</div>
```

内置参数化模板也渲染成同样的根节点，只是内容由参数（背景色、边框、高亮等）生成。核心是：

- 根节点 `position:relative` + 固定尺寸 + `overflow:hidden`
- 装饰层（边框/卡片/图案）用绝对定位子节点
- 文字层 `z-index` 高于装饰层

### 4.5 内容卡 DOM 结构

```html
<div class="sticker-card" style="position:relative;width:900px;height:1200px;overflow:hidden;border-radius:32px;box-sizing:border-box;background-image:url(...);background-size:cover;background-position:center;">
  <!-- 小标题区域 -->
  <div class="sticker-card-zone" style="position:absolute;left:10%;top:10%;width:80%;height:18%;
       font-size:30px;color:#1A1A1A;font-weight:800;text-align:center;line-height:1.4;
       display:-webkit-box;-webkit-line-clamp:2;-webkit-box-orient:vertical;overflow:hidden;white-space:pre-wrap;">
    巨蟹座：孝顺是接起电话的那一刻
  </div>

  <!-- 正文区域 -->
  <div class="sticker-card-zone" style="position:absolute;left:10%;top:32%;width:80%;height:55%;
       font-size:24px;color:#333333;font-weight:500;text-align:left;line-height:1.4;
       display:-webkit-box;-webkit-line-clamp:10;-webkit-box-orient:vertical;overflow:hidden;
       overflow-wrap:anywhere;white-space:pre-wrap;">
    父母打来的电话，不管在开会还是在做饭，他们都会接。
  </div>
</div>
```

### 4.6 文字区域 → CSS 映射

模板中的文字区域字段（百分比）按以下公式转 CSS：

| 字段 | CSS |
| --- | --- |
| x | `left: {x}%` |
| y | `top: {y}%` |
| w | `width: {w}%` |
| h | `height: {h}%` |
| size | `font-size: {size}px`（900 设计稿基准） |
| color | `color: {color}` |
| align | `text-align: left/center/right` |
| bold | `font-weight: 800 / 500` |
| maxLines | `-webkit-line-clamp: {maxLines}` + `display:-webkit-box; -webkit-box-orient:vertical; overflow:hidden` |

字体建议使用中文字体栈：

```text
标题：'Smiley Sans','Microsoft YaHei',sans-serif
正文：'Microsoft YaHei','PingFang SC',sans-serif
衬线：'SimSun','Songti SC',serif
楷体：'KaiTi','STKaiti','SimSun',serif
等宽：'Courier New','SimSun',serif
```

接入方如使用网页渲染，需要确保字体已加载完成再截图，否则可能出现字体回退。

### 4.7 customCSS 约定

自定义模板可携带 `customCSS` 字符串，渲染时以 `<style>` 标签注入模板根节点内部。

约定选择器：

| 选择器 | 作用 |
| --- | --- |
| `.sticker-cover` | 首图根节点 |
| `.sticker-card` | 内容卡根节点 |
| `.sticker-cover-zone` | 首图文字区域 |
| `.sticker-card-zone` | 内容卡文字区域 |

customCSS 只允许覆盖样式，不允许改变布局结构（根节点尺寸、定位方式保持规格不变）。

### 4.8 渲染步骤（伪代码）

```text
1. 解析模板：
   - 内置模板：按参数生成装饰层样式
   - 自定义模板：读取 bgImage / cardBgImage / coverZones / cardZones / customCSS

2. 构建 Cover DOM：
   - 根节点 900×1200，背景 = bg 或背景图
   - 有 coverZones → 按区域放置标题文本
   - 无 coverZones → 默认居中排版（标题 + 首段描述）
   - 注入 customCSS

3. 构建 Card DOM（每段一张）：
   - 根节点 900×1200，背景 = bg 或 cardBgImage
   - 有 cardZones → 小标题区域 + 正文区域
   - 无 cardZones → 默认卡片结构（顶部徽章/页码 + 居中正文）
   - 注入 customCSS

4. 等待字体与图片加载完成

5. 逐张截图：
   - 预览尺寸节点 → toPng(node, { pixelRatio: 900 / 节点宽 })
   - 输出 PNG dataURL

6. 返回 { cover, cards }
```

### 4.9 注意事项

- **背景图**：建议使用 dataURL，避免跨域导致截图白屏；网络图需确保 CORS 允许
- **文字溢出**：区域固定 + `-webkit-line-clamp` 截断，不会撑破画布
- **换行**：正文使用 `white-space: pre-wrap`，保留段落内换行
- **截图背景**：根节点背景不能透明（贴图需要实体背景），`backgroundColor: 'transparent'` 只作用于节点外部
- **性能**：一段文字一张卡，一次生成 3~9 张图，建议并行截图

## 5. 发布

### 5.1 支持范围

- 贴图仅发布到**公众号 / 小红书**（不支持头条号、百家号）
- 公众号仅支持推送草稿箱

### 5.2 发布正文规则

- **不传平台标题**（标题字段为空）
- 正文 = 贴图标题 + 话题（中间大段描述已渲染进图片，不再发布）

```text
十二星座里，真正把孝顺刻进骨子里的，是这三个

#星座孝顺 #巨蟹座 #金牛座 #处女座 #十二星座
```

### 5.3 发布参数示例

```json
{
  "platform": "wechat",
  "postType": "sticker",
  "title": "",
  "content": "十二星座里，真正把孝顺刻进骨子里的，是这三个\n\n#星座孝顺 #巨蟹座 #金牛座 #处女座 #十二星座",
  "images": [
    "首图PNG",
    "内容卡PNG 1",
    "内容卡PNG 2"
  ],
  "saveDraftOnly": false
}
```

## 6. 自动托管中的贴图

- 任务类型选择「贴图」
- 内容来源：我的素材 / 今日热点 / 微信爆文
- 绑定首图模板（自定义模板同样可选）
- 每次成功发布按 `贴图 10 积分/条` 扣费
- 素材使用后标记已用，不重复发布

## 7. 接入建议

1. **模板层**：复用 `StickerCoverTemplate` 数据结构，内置 + 自定义模板统一管理
2. **生成层**：调用主站 AI 网关生成标题/正文/话题，按固定输出格式解析
3. **渲染层**：用 HTML/CSS 模板渲染 PNG，自定义模板支持背景图 + 文字区域 + customCSS
4. **发布层**：贴图只发公众号/小红书，标题传空，正文只含标题 + 话题
5. **计费层**：贴图生成成功后扣 10 积分；素材 AI 生成按 2 积分/条
