# 万稿汇 1.0.0

从热点选题到文章发布，一站完成 AI 写作、改文、去 AI 味与排版。

## 下载与安装

本次提供 **Mac 自签名版**和 **Windows x64 未签名版**。

| 你的电脑 | 安装包 |
| --- | --- |
| Mac Apple Silicon（M1 / M2 / M3 等） | `AIMedia-1.0.0-mac-arm64.dmg` |
| Mac Intel | `AIMedia-1.0.0-mac-x64.dmg` |
| Windows 64 位 | `AIMedia-1.0.0-win-x64-Setup.exe` |

从下方 Assets 下载 DMG，将应用拖入「应用程序」。ZIP 为相同架构的压缩包，`SHA256SUMS.txt` 可用于核对下载文件。

Windows 双击 Setup.exe 按提示安装。此安装包没有代码签名证书，首次运行可能出现 SmartScreen 提示；确认来源为本仓库后再继续。

Mac 版使用 ad-hoc 自签名，未经过 Apple 公证。如果 macOS 拦截，请确认下载自本仓库，再在「系统设置 → 隐私与安全性」中允许打开。后续更新会提示前往 GitHub 手动下载安装。

## 主要功能

- 热点、微信爆文与个人文字、图片素材管理。
- AI 写作与改文：两步创作流程，生成后选模板、编辑和预览。
- 器灵去 AI 味：确认费用后处理，预览满意再采用。
- 平台账号管理、待发布队列、发布记录与定时托管。
- 历史作品搜索与分页，统一简洁界面。
- 无需激活；支持自定义文本接口，也可使用器灵一键授权。

## 开始使用

1. 打开「AI 配置」，使用器灵一键授权，或填写自己的接口地址、模型名称和 API Key。
2. 在「创作工坊」输入主题或原文，设置字数与配图后生成。
3. 进入「样式与编辑」，选模板、修改正文并预览。
4. 需要发布时，在「账号中心」登录账号，再到「内容发布」操作。

AI 服务按所选服务商规则计费，API Key 保存在本机。
