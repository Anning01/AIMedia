# 万稿汇 1.0.5

修复头条图库图片发布、公众号托管目标账号和编辑器撤销操作。

## 更新内容

- 头条发布支持读取「我的图库」本地图片，上传后分别使用正文图片和封面的平台 URI；上传失败会直接提示，不再提交失效的本地地址。
- 头条「发布文章」直接提交发布，移除强制先存草稿的额外请求。已通过软件实际发布验证，正文图片和封面正常显示。
- 修复多个公众号托管任务可能投递到同一账号的问题：切换目标账号、校验身份和推送草稿串行执行，拒绝目标缺失或已停用的任务。
- 创作工坊增加撤销、重做按钮及快捷键，可恢复误删的文字、段落和图片；载入其他作品时重新建立编辑历史。
- 公众号操作继续只推送到草稿箱，由作者在公众号后台自行确认发布。

## 已知问题

头条「保存到平台草稿箱」仍可能返回 `7050：保存失败`，本次未修复。需要直接发布时请选择「发布文章」。

## 验证范围

头条图库图片已完成真实发布核对；公众号账号隔离、编辑撤销及失败处理通过本地回归测试，公众号验证使用模拟响应，未实际发布公众号内容。
