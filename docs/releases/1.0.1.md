# 万稿汇 1.0.1

修复 1.0.0 安装版器灵一键授权后提示 `Not Found` 的问题。

## 修复内容

- 模型列表改用器灵当前的 `/v1/models` 接口，恢复一键授权、手动 Key 验证和文本模型选择。
- 同步修复文本生成与费用预估接口，适配当前的正文、用量、价格和错误返回格式。
- 保留生成前预算检查、请求记录、停止等待和防重复提交逻辑。
- 发布前直接验证安装包内的授权与模型调用模块，测试使用模拟服务，不产生真实模型费用。

## 下载与安装

| 你的电脑 | 安装包 |
| --- | --- |
| Mac Apple Silicon（M1 / M2 / M3 等） | `AIMedia-1.0.1-mac-arm64.dmg` |
| Mac Intel | `AIMedia-1.0.1-mac-x64.dmg` |
| Windows 64 位 | `AIMedia-1.0.1-win-x64-Setup.exe` |

Mac 下载 DMG 后将应用拖入「应用程序」替换旧版。使用 ad-hoc 自签名，未经过 Apple 公证；如被拦截，请确认下载自本仓库，再按「系统设置 → 隐私与安全性」提示允许打开。

Windows 运行 Setup.exe 更新安装。本版未使用代码签名证书，首次运行可能出现 SmartScreen 提示，请确认来源。

原有本机素材、作品与 AI 配置继续保留。此前一键授权失败的用户，请在更新后重新点击授权。Windows 支持检查更新；Mac 自签名版需手动下载安装。

ZIP 为对应 Mac 架构的压缩包；`SHA256SUMS.txt` 可用于核对下载文件。
