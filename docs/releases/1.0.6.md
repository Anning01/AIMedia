# 万稿汇 1.0.6

修复数据持久化异常、托管任务去 AI 味功能及在线更新检测机制。

## 更新内容

- 修复软件关闭重启后账号与素材丢失、需要重新登录的问题：优化本地数据落盘与加密策略，修复多重保存下的凭据二次加密 Bug，确保账号凭据、素材组、图片及托管任务在关闭后完全持久化。
- 修复公众号托管任务「去 AI 味」API 调用：打通参数透传链路，修复执行逻辑中引用丢失问题；增加历史中断死任务超时自动释放机制，防止任务永久锁死与重复扣费。
- 增强在线更新（AutoUpdater）：支持网络重定向多跳追踪，新增 GitHub Releases 官方备用探针，解决 API 限制导致的检查失败；优化检查更新交互与状态反馈。
