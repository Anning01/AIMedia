# 万稿汇 1.0.3

器灵 AI 配置界面优化，支持思考模式设置。

## 更新内容

- 模型、思考模式和预算集中展示，服务连接信息独立分区，减少重复边框与提示。
- 思考模式提供「默认 / 开启 / 关闭」，仅在模型声明支持时展示。
- **默认完全不发送 `thinking` 参数，由服务端决定模型行为**；选择开启或关闭才显式发送对应设置。
- 点击「保存模型与设置」生效，重启后恢复；切换模型会按能力调整可选设置。
- 费用预估与实际生成使用同一思考模式；切换模式不会绕过原请求待核对保护。
- 思考模式支持键盘操作，布局检查覆盖 1024×768、1280×800 和 1440×900 窗口。

## 安装包

| 系统 | 文件 |
| --- | --- |
| Mac Apple Silicon | `AIMedia-1.0.3-mac-arm64.dmg` |
| Mac Intel | `AIMedia-1.0.3-mac-x64.dmg` |
| Windows x64 | `AIMedia-1.0.3-win-x64-Setup.exe` |

Mac 使用 ad-hoc 自签名，未经过 Apple 公证；Windows 安装包未签名，系统可能提示未知开发者。请确认从本仓库下载安装。更新保留本机素材、作品和 AI 配置。

安装后打开「AI 配置 → 器灵服务」，刷新模型，选择思考模式并保存。此前已保存的显式开启或关闭设置继续保留，选择「默认」可恢复由系统决定。

提供 Mac ZIP、平台更新清单与 `SHA256SUMS.txt`。测试使用模拟服务，不产生真实模型费用。
