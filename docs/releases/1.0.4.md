# 万稿汇 1.0.4

公众号内容统一推送到草稿箱，由作者在公众号后台确认发布。

## 更新内容

- 创作工坊、内容发布、历史重试和自动托管中的公众号操作均只推送草稿箱。
- 已有公众号托管任务自动按草稿箱方式执行，无需手动修改旧任务。
- 文章和贴图保留草稿创建、编辑及排版能力；处理成功统一记录为「已存草稿」。
- 保留器灵配置新布局，以及「默认 / 开启 / 关闭」思考模式；默认不发送思考模式参数。
- 保留素材、作品、账号登录态和 AI 配置，无需数据迁移。

## 下载安装

| 系统 | 安装包 |
| --- | --- |
| Mac Apple Silicon（M1 / M2 / M3 等） | `AIMedia-1.0.4-mac-arm64.dmg` |
| Mac Intel | `AIMedia-1.0.4-mac-x64.dmg` |
| Windows x64 | `AIMedia-1.0.4-win-x64-Setup.exe` |

Mac 打开 DMG 后将应用拖入「应用程序」；Windows 运行安装程序按提示更新。

Mac 使用 ad-hoc 自签名，未经过 Apple 公证；Windows 安装包未签名。系统可能显示未知开发者提示，请确认从本仓库下载后按系统提示操作。

提供 Mac ZIP、平台更新清单和 `SHA256SUMS.txt`，用于手动安装、更新检查与文件校验。

## 开始使用

1. 打开「AI 配置」，使用器灵一键授权或自己的文本接口。
2. 在「创作工坊」生成、编辑并选择排版模板。
3. 在「账号中心」登录公众号账号，再将作品推送到草稿箱。
4. 打开公众号后台检查草稿，确认后自行发布。
