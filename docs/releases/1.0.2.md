# 万稿汇 1.0.2

器灵一键授权和账号页面完整保留来源站点。

## 更新内容

- 一键授权支持可选分站来源，原样打开服务端返回的授权地址，支持登记的自定义域名。
- 使用记录、充值余额和 Key 管理跟随当前来源站点，不再固定跳转主站。
- 来源与站点地址保存在本机，重启后恢复；切换来源会清除旧地址并停止旧授权。
- 分站不存在、停用或域名配置错误时提示联系分站管理员，不自动回退主站。
- 模型 API 继续使用统一地址，浏览器授权账号的 Key、余额和调用归属保持独立。

当前开源版无需软件激活，没有分站来源的用户仍使用主站。

## 安装包

| 系统 | 文件 |
| --- | --- |
| Mac Apple Silicon | `AIMedia-1.0.2-mac-arm64.dmg` |
| Mac Intel | `AIMedia-1.0.2-mac-x64.dmg` |
| Windows x64 | `AIMedia-1.0.2-win-x64-Setup.exe` |

Mac 使用 ad-hoc 自签名，未经过 Apple 公证；Windows 安装包未签名，系统可能提示未知开发者。确认下载来源后再安装。保留原有本机素材、作品和 AI 配置。

提供对应 Mac ZIP、平台更新清单与 `SHA256SUMS.txt`。发布前使用模拟接口直接验证成品中的授权、来源恢复、站点跳转、预算与生成逻辑，不调用真实付费模型。
