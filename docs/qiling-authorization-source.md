# 一键授权的分站来源

万稿汇当前为免激活开源版，没有器灵软件授权登录会话，因此默认不传 `site_code`，保持主站兼容；不从浏览器中的 AI 付款账号推断来源。

一键授权支持可选来源参数。下游集成若已有软件授权登录或校验上下文，使用该响应的 `site.code`，在切换授权上下文后发起：

```ts
await window.wangaohui.qilingAuthStart({
  site_code: licenseSession?.site?.code || "",
});
```

参数只接收分站标识，不接收域名、URL 或重定向地址。没有来源的上下文显式传空字符串，清除上一次来源；`platform` 也由服务端按主站处理。不增加分站选择器，不把 AI 账号 B 的站点用作软件账号 A 的来源。

主进程把来源作为独立元数据存入原有 `ai-config.json` 的 `settings.qilingAuthSiteCode`。不传参数再次授权时使用已保存来源，支持重启恢复。这里不存软件会话或授权凭证，也不将来源用于软件激活或权益判断。切换来源会使仍在等待的旧授权失效，旧响应不能保存 Key。

主进程从服务端的 `verification_url` 提取站点 origin，存入同一设置中的 `qilingWebsiteOrigin`，不保存确认页查询参数或授权凭证。「使用记录」「充值余额」「Key 管理」都使用这个来源站点。切换来源会清除旧站点；只有来源标识而没有站点地址的旧配置，通过统一 API 创建授权请求来解析服务端登记的站点，仅提取 origin，不打开确认页、不领取 Key。无来源的旧配置使用统一 API 的默认主站地址。分站解析失败时停止跳转，不静默回退主站。

创建请求仍发往原先配置的器灵 API，仅增加可选 `site_code`。浏览器原样打开该响应的完整 HTTPS `verification_url`，支持服务端登记的分站和自定义域名；不自行拼接域名，不把确认页域名或领取响应中的地址改成模型 API 地址。

分站 404/409 会保留原错误并提示联系分站管理员，不重试、不回退主站。来源修改不改变已保存的 Key、模型、预算或自定义接口配置；API Key 继续由原有系统安全存储加密保存。

验证：`npm run check:qiling` 使用本地模拟 HTTP 和隔离数据目录，覆盖主站/分站/自定义域名、来源持久化与切换、404/409 不回退、Key 与 API 地址独立、取消和旧响应处理。没有真实授权确认或付费模型调用。
