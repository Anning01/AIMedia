# 贴图生成实现指南（模板 → 成品）

> 本文档描述从用户输入到贴图成品的完整实现流程。其他子应用可仅依据本文档独立实现，
> 不依赖万稿汇客户端源码。涉及模板数据结构、AI 生成、内容结构化、渲染、发布全链路。

## 1. 总览

```text
输入：主题/素材 + 模板 + 字数限制
  │
  ▼
① AI 生成：标题 + 分段正文 + 话题
  │
  ▼
② 内容结构化：标题、段落、小标题、话题
  │
  ▼
③ 模板解析：内置参数 / 自定义背景图+文字区域+customCSS
  │
  ▼
④ 渲染：首图 1 张 + 内容卡 N 张（HTML/CSS → PNG 900×1200）
  │
  ▼
⑤ 成品：{ cover, cards, title, topics }
  │
  ▼
⑥ 发布：公众号/小红书，正文 = 标题 + 话题
```

核心规则：

- 文字渲染进图片，图片即成品
- 发布时不传平台标题，正文只含标题和话题
- 每段正文一张内容卡，话题放最后一张

## 2. 输入定义

```json
{
  "topic": "十二星座里，真正把孝顺刻进骨子里的，是这三个",
  "template": { "id": "f01" },
  "wordLimit": 400
}
```

说明：

- `topic`：用户输入的贴图主题或素材
- `template`：模板 id 或完整模板 JSON（见第 4 节）
- `wordLimit`：正文总字数上限，支持 400 / 300 / 200 字以内，默认 400

## 3. ① AI 生成

### 3.1 请求

调用任意支持中文的 LLM（接入方可通过万稿汇主站 AI 网关，也可自行接入模型）。

系统提示词（建议原样使用）：

```text
你是资深公众号贴图内容策划。根据输入的内容，提取关键信息，去掉无用广告和清洗不干净的遗留信息，
生成一条公众号贴图内容：
第一行是贴图标题（一句有吸引力的短句，不超过 25 个字）；
接着是正文描述（口语化、有画面感，按段落输出，每段 60~100 字左右，
段落之间用空行分隔，每段适合单独做成一张卡片，允许用简短的小标题段引领）；
不要任何 Markdown 标记、列表符号或格式符号；
最后另起一行生成 3 到 5 个合适的话题，每个话题以 # 开头、用空格分隔。
只输出标题、正文和话题，不要任何额外说明。
```

用户提示词：

```text
贴图主题：{topic}
字数：{wordLimit} 字以内
```

### 3.2 输出样例

```text
十二星座里，真正把孝顺刻进骨子里的，是这三个
前几天在家庭群里看到一条消息，朋友发了一张截图，上面写着“十二星座孝顺排行榜”。

巨蟹座：孝顺是接起电话的那一刻
父母打来的电话，不管在开会还是在做饭，他们都会接。
他们记得住父母随口提过的一句“想吃老家那种腌萝卜”，下次回家的时候就真的带了一罐。

金牛座：孝顺是转账记录里那些不算大也不算小的数字
逢年过节，红包准时到账。换季的时候，不用父母开口，衣服鞋子已经寄到了家。

#星座孝顺 #巨蟹座 #金牛座 #处女座 #十二星座
```

### 3.3 解析算法

```text
1. 按行拆分，去掉空行
2. 第 1 行 = 标题（截断不超过 25 字）
3. 从第 2 行起，遇到第一个以 # 开头的行开始，后面的都是话题
4. 话题行之间：用空格或换行分隔，统一保留 #xxx 形式
5. 中间部分 = 正文；按空行切分为段落：
   - 若某段只有一行且 ≤ 20 字且句末无标点 → 视为小标题段（heading）
   - 其余段落 → 正文段（text）
```

段落切分示例：

| 段落 | 类型 |
| --- | --- |
| 巨蟹座：孝顺是接起电话的那一刻 | 小标题段 |
| 父母打来的电话……真的带了一罐。 | 正文段 |
| 金牛座：孝顺是转账记录里…… | 小标题段 |
| 逢年过节…… | 正文段 |

解析失败兜底：如果 AI 返回不是预期格式，按空行分段，第一行当标题，其余全部当正文。

### 3.4 生成数量

- 1 个标题
- 3~9 段正文（建议上限 9，避免发布图太多）
- 3~5 个话题

## 5. ③ 渲染规格

### 5.1 输出

- 首图 1 张：900 × 1200 PNG
- 内容卡 N 张：每段正文一张，900 × 1200 PNG
- 话题作为最后一张内容卡的文本（不单独成图）

### 5.2 渲染技术

HTML + 内联样式构建 DOM，`html-to-image`（或等价库）截图：

```js
const pixelRatio = Math.max(900 / node.offsetWidth, 1200 / node.offsetHeight);
const png = await toPng(node, { pixelRatio, cacheBust: true, backgroundColor: 'transparent' });
```

### 5.3 首图 DOM

```html
<div class="sticker-cover"
     style="position:relative;width:900px;height:1200px;overflow:hidden;
            background:#FFD60A;border-radius:12px;box-sizing:border-box;">
  <!-- 背景图（自定义模板） -->
  <div style="position:absolute;inset:0;background-image:url(data:image/png;base64,...);
              background-size:cover;background-position:center;"></div>

  <!-- 文字区域 -->
  <div class="sticker-cover-zone"
       style="position:absolute;left:12%;top:36%;width:76%;height:24%;
              font-size:58px;color:#1A1A1A;font-weight:800;text-align:center;
              font-family:'Smiley Sans','Microsoft YaHei',sans-serif;line-height:1.35;
              display:-webkit-box;-webkit-line-clamp:2;-webkit-box-orient:vertical;
              overflow:hidden;overflow-wrap:anywhere;white-space:pre-wrap;">
    十二星座里，真正把孝顺刻进骨子里的，是这三个
  </div>

  <style>.sticker-cover-zone { letter-spacing: 0.02em; }</style>
</div>
```

内置模板：装饰层（边框、图案、徽章、页码、箭头）用绝对定位子节点生成，文字层 `z-index:2` 置于其上。

### 5.4 内容卡 DOM

```html

     style="position:relative;width:900px;height:1200px;overflow:hidden;border-radius:32px;
            box-sizing:border-box;background-image:url(...);background-size:cover;background-position:center;">
  <div class="sticker-card-zone"
       style="position:absolute;left:10%;top:10%;width:80%;height:18%;
              font-size:30px;color:#1A1A1A;font-weight:800;text-align:center;line-height:1.4;
              display:-webkit-box;-webkit-line-clamp:2;-webkit-box-orient:vertical;overflow:hidden;
              white-space:pre-wrap;">
    巨蟹座：孝顺是接起电话的那一刻

       style="position:absolute;left:10%;top:32%;width:80%;height:55%;
```

### 5.5 文字区域 → CSS 映射

| 字段 | CSS |
| --- | --- |
| x | `left:{x}%` |
| y | `top:{y}%` |
| w | `width:{w}%` |
| h | `height:{h}%` |
| size | `font-size:{size}px` |
| color | `color:{color}` |
| align | `text-align:{align}` |
| bold | `font-weight:800` / `500` |
| maxLines | `-webkit-line-clamp:{n}` + `display:-webkit-box;-webkit-box-orient:vertical;overflow:hidden` |

### 5.6 内置模板的默认排版（无文字区域时）

- 布局：`layout` 决定文字垂直位置（top/center/bottom）
- 标题字号：`900 × titleSize / 100` px
- 正文第一段截取 36 字作为副标题：`900 × textSize / 100` px
- 徽章：`900 × 2.6 / 100` px
- 高亮：标题末尾 1~2 字按 `highlight` 样式强调

### 5.7 正文自适应字号（内容卡无文字区域时）

在 900×1200 画布上，正文区域约 686 × 793px，按内容长度自动缩小字号：

```js
function fitBodySize(text) {
  const contentW = 686;  // 900 画布正文区宽
  const contentH = 793;  // 900 画布正文区高
  let size = 40;         // 起始字号
  const minSize = 28;
  while (size > minSize) {
    const perLine = Math.max(1, Math.floor(contentW / size));
    const lines = Math.max(1, Math.ceil(text.length / perLine));
    if (lines * size * 1.7 <= contentH) return size;
    size -= 2;
  }
  return size;
}
```

### 5.8 字体

```text
smiley：'Smiley Sans','Microsoft YaHei',sans-serif
sans：  'Microsoft YaHei','PingFang SC',sans-serif
serif： 'SimSun','Songti SC',serif
kaiti： 'KaiTi','STKaiti','SimSun',serif
type：  'Courier New','SimSun',serif
```

渲染前必须等待字体加载完成。

### 5.9 customCSS 选择器

| 选择器 | 作用 |
| --- | --- |
| `.sticker-cover` | 首图根节点 |
| `.sticker-card` | 内容卡根节点 |
| `.sticker-cover-zone` | 首图文字区域 |
| `.sticker-card-zone` | 内容卡文字区域 |

### 5.10 渲染注意事项

- 背景图建议 dataURL，避免跨域白屏
- 根节点必须实体背景，截图库的透明背景只作用于节点外部
- 文字用 `-webkit-line-clamp` 截断，防止溢出画布
- 多张卡并行截图，缩短生成时间

## 6. ④ 生成编排（伪代码）

```text
function generateSticker(topic, template, wordLimit):
    # 1. AI 生成
    raw = llm(systemPrompt, userPrompt(topic, wordLimit))

    # 2. 结构化
    title, paragraphs, topics = parseSticker(raw)

    # 3. 渲染首图
    coverNode = buildCoverDom(template, title)
    cover = screenshot(coverNode, 900, 1200)

    # 4. 渲染内容卡
    cards = []
    for para in paragraphs:
        heading = para.isHeading ? para.text : null
        text = para.isHeading ? null : para.text
        node = buildCardDom(template, heading, text)
        cards.push(screenshot(node, 900, 1200))

    # 5. 话题作为最后一张卡（可选）
    if topics:
        node = buildCardDom(template, null, topics)
        cards.push(screenshot(node, 900, 1200))

    return { cover, cards, title, topics }
```

## 8. 完整示例

**输入**

```text
topic = "为什么越追求完美的母亲越累"
template = 自定义模板（背景图 + 首图标题区 + 内容卡标题/正文区）
wordLimit = 400
```

**AI 输出**

```text
越是想做个完美的母亲，越有可能剥夺孩子的“生存能力”
你有没有想过，在孩子面前，要做一个多么“称职的母亲”呢？

追求完美的母亲首先会让自己疲惫不堪
孩子的便当色彩鲜艳，每天看作业，周末带孩子去公园玩。

表现出“做不到”其实是需要勇气的
“妈妈，这个太难了，能和我一起想吗？”——这里需要的是告诉对方“我做不到”。

#亲子 #育儿 #母亲 #家庭教育
```

**结构化**

```text
title: 越是想做个完美的母亲，越有可能剥夺孩子的“生存能力”
cards:
  1. heading=null, text=你有没有想过……称职的母亲”呢？
  2. heading=追求完美的母亲首先会让自己疲惫不堪, text=孩子的便当……公园玩。
  3. heading=表现出“做不到”其实是需要勇气的, text=“妈妈，这个太难了……做不到”。
  4. heading=null, text=#亲子 #育儿 #母亲 #家庭教育（话题卡）
```

**成品**

- 首图 1 张：标题渲染到首图背景图指定区域
- 内容卡 4 张：3 段正文 + 1 张话题卡
- 发布正文 = 标题 + 话题

## 9. 边界情况处理

| 情况 | 处理 |
| --- | --- |
| AI 输出没有话题 | 发布正文只含标题 |
| AI 输出没有标题 | 取第一段前 25 字当标题 |
| 段落过长 | 自适应字号缩小；仍放不下则按区域截断 |
| 模板没有文字区域 | 使用默认居中排版 |
| 自定义模板缺背景图 | 回退使用模板 bg 色 |
| 图片加载失败 | 跳过该背景图，保留背景色 |
| 话题卡内容过长 | 按区域截断 |
