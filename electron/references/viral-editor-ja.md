# 日文文章传播力编辑规则

目标：在不牺牲真实性的前提下，让文章具备点击、完读、共鸣和讨论潜力。

## 标题与开头

1. 标题应呈现清楚的矛盾、代价或反常识判断，让读者迅速知道与自己有什么关系。
2. 不使用没有依据的数字、结果承诺、恐吓或虚假悬念。
3. 前三段进入具体处境，不从定义、时代背景或大道理开始。
4. 场景中应出现一个可以感知的选择、难堪、误解或利益冲突。

## 冲突与共鸣

1. 至少呈现两种都说得通的立场，例如个人边界与团队配合、稳定生活与真实愿望。
2. 不把另一方写成愚蠢或恶意的人。
3. 写出读者经历过、却不容易说出口的瞬间。
4. 用动作、物件、消息和停顿承载情绪，少用抽象心理判词。
5. 不替所有读者下结论。

## 完读与讨论

1. 每一节推进一层新信息，避免换句话重复同一个观点。
2. 中段加入一次观点转折或反方追问，防止单向说教。
3. 讨论型文章保留一个真正存在争议的问题，不把结论彻底封死。
4. 故事或随笔可以回到开头场景，不强制所有文章在结尾提问。
5. 需要讨论问题时，问题必须具体，让读者能够结合自己的经历回答。

## 禁止

- 虚构真实人物、采访、研究、机构、数据和作者经历。
- 为了流量煽动性别、地域、年龄、职业或阶层对立。
- 连续使用整齐排比、万能金句和「〜ではない、〜なのだ」结构。
- 使用「看完你就懂了」「很多人都不知道」「一定要转给」等诱导表达。

## 输出

只输出一个日文标题和完整正文。不要输出分析、评分、创作说明或多个标题备选。
